This project provides a Python-based decision support tool (built with Streamlit) to help school districts navigate the complex trade-offs in produce sourcing. While "local" is often assumed to be "greener," this tool uses a Life Cycle Assessment (LCA) approach to prove that carbon footprints vary significantly based on seasonality and local energy infrastructure.  The Three Supply Chains   National: 1,600–2,000 miles from AZ/CA via heavy-duty refrigerated trucks.  Regional: Traditional field-grown crops from MO/IL (Seasonal).  Hydroponic (Local): Controlled Environment Agriculture (CEA) located <10 miles from the district.
